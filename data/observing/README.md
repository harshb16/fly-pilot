# Fly-observing-expert recordings

Generated by:

```bash
python -m fly_pilot.record_observing --episodes 3 --seed 0 --output data/observing/expert_observing.parquet
```

ExpertLandingController (classical autopilot) flies the Cessna. MaleCNS
observes a rendered fly-view. The fly does **not** control the aircraft.

Replay without the browser:

```bash
python -m fly_pilot.brain.replay_episode data/observing/expert_observing.parquet
```

Parquet + `.meta.json` sidecar are gitignored.
