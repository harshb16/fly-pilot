# Fly-observing-expert recordings

Generated by:

```bash
python -m fly_pilot.record_observing --episodes 3 --seed 0 --output data/observing/expert_observing.parquet
python -m fly_pilot.record_observing --episodes 3 --seed 51000 --success-only --output data/observing/decoder_replay.parquet
```

The second command keeps a few **full retinal** episodes next to the compact
decoder-training set (`data/decoder/`) so MaleCNS replay stays reproducible.
ExpertLandingController (classical autopilot) flies the Cessna. MaleCNS
observes a rendered fly-view. The fly does **not** control the aircraft.

Replay without the browser:

```bash
python -m fly_pilot.brain.replay_episode data/observing/decoder_replay.parquet
```

Parquet + `.meta.json` sidecar are gitignored.
